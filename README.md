# 万年筆 筆記シミュレーター

万年筆のペン先・インク・紙を選んで、画面に手書きできる Web アプリです。ペン先の地金によるしなり、字幅、筆圧による線幅の変化、インクの濃淡やにじみを再現します。書いたものは PNG・JPG・PDF で保存できます。

ビルド不要の静的ページで、ブラウザだけで動作します。画面は日本語と英語に対応しています（右上のボタンで切り替え。英語のブラウザでは自動で英語表示。`?lang=en` / `?lang=ja` でも指定できます）。筆圧対応のペン（Apple Pencil、ペンタブレットなど）では実際の筆圧を使います。

## できること

| 項目 | 内容 |
|---|---|
| 地金 | ステンレス、14金、18金、21金、22金、23金。柔らかいほど弱い筆圧から開き、太くなる（21〜23金は国産のみ） |
| 字幅 | UEF、EF、F、FM、M、B、BB、BBB。国産／海外製の切り替え（海外製は同じ表記でも太め） |
| ペン先の種類 | ノーマル／スタブ（縦太・横細、書く向きで線幅が変わる）／フレックス（筆圧で大きく変化） |
| インク | ブルー、ブルーブラック、ブラック、レッドと、それぞれの系統 8 色のカラーチャート、任意の色 |
| コンディション | 良好／掠れる／インクが続かない／インク切れ間近（補充ボタンあり） |
| 紙 | 白紙、横罫線（7mm）、縦罫線（便箋）、原稿用紙（400字）、和紙（よくにじむ）。A5 横、A4 縦、はがき。白・クリーム |
| 罫線の色 | 標準（横罫は青、縦罫・原稿用紙は朱）、青、朱、緑、茶、グレー、紺、黒 |
| 表示 | 全体、実寸、2 倍、4 倍 |
| 保存 | PNG・JPG（300dpi）、PDF（紙の実寸。等倍で印刷すると線幅も実物どおり） |

画面上部の試し書き欄に、選んだペン先で筆圧を弱から強へ上げながら書いた見本線を 3 倍で表示します。

## 線幅の目安（mm、通常の筆圧）

| 字幅 | UEF | EF | F | FM | M | B | BB | BBB |
|---|---|---|---|---|---|---|---|---|
| 国産 | 0.15 | 0.22 | 0.30 | 0.38 | 0.45 | 0.58 | 0.75 | 0.95 |
| 海外製 | 0.20 | 0.32 | 0.42 | 0.50 | 0.58 | 0.75 | 0.95 | 1.20 |

一般的な目安の値で、特定の製品の実測値ではありません。値は `nib.js` の `WIDTH`、地金ごとのしなりは `METALS` で調整できます。

## ファイル構成

```
index.html        画面と描画（Canvas、Pointer Events）
nib.js            ペン先・インク・コンディションのモデル（ブラウザと Node.js の両方で動作）
test/check-nib.js モデルの検証
```

## 使い方

`index.html` をブラウザで開くだけで動きます。GitHub Pages で公開する場合は、Settings → Pages で `main` ブランチのルートを指定してください。

PDF の書き出しには jsPDF（cdnjs から読み込み）を使います。

## テスト

```
node test/check-nib.js
```
